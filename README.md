# itease-artes
Artes públicas das redes sociais da iTease (Marketing IA).

- `artes/AAAA-MM-DD/` — imagens JPEG publicadas no Instagram e no LinkedIn (geradas pelo agente Publicador).
- `ferramentas/render_artes.py` — gera as artes 1080×1350 a partir do JSON dos posts.
- `marca/logo-branco.png` — logo iTease (branco, fundo transparente).

Este repositório é público de propósito: o Instagram só aceita imagens em link público.
Não coloque aqui nada que não possa ser público.
